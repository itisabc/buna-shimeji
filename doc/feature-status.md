# 機能対応表（Feature Status）

本プロジェクトは、Java 版 Shimeji-ee / Shimeji-Desktop 系（参考実装）の
Windows 用デスクトップマスコット「しめじ」を Rust で再実装したものです。
本書は「現時点でどこまで移植できているか」の一覧です。

- 対象: Phase 1（タスク #0〜#30）完了時点
- 検証: `cargo test` **495/495 PASS**（2026-09-12）
- 対応表の粒度: 機能単位（Java 版のクラス名は記載しません）

凡例: ✅ 実装済み / ⚠️ スタブ（未実装・資産未使用）

## 1. コア挙動（実装済み）

| 機能 | 内容 | 状態 |
|---|---|---|
| 歩行・走行 | 床・壁・天井・ウィンドウ上を歩く | ✅ |
| 落下・着地 | 重力落下、床/天井/壁の境界判定 | ✅ |
| ジャンプ | 放物線ジャンプ、壁や窓からの踏切 | ✅ |
| 壁・天井の移動 | のぼる・ぶら下がる・伝う | ✅ |
| ドラッグ | マウスでつかんで移動、離すと投げられる | ✅ |
| 増殖（分裂） | マスコットが 2 体に分裂 | ✅ |
| 変身 | 画像セット（亜種）への切替 | ✅ |
| ウィンドウ運び | ウィンドウを保持して歩く/落ちる/投げる/ぶら下がる | ✅ |
| ウィンドウ最前面固定 | マスコットを窓にドラッグ&ドロップしてその窓を最前面に固定（Rust 版の追加機能）。トレイで ON/OFF（既定 OFF） | ✅ |
| 画面間移動 | マルチモニタ間の移動 | ✅ |
| 透過描画 | CreateDIBSection + UpdateLayeredWindow | ✅ |
| 単一起動 | 名前付き mutex で多重起動を防止 | ✅ |

## 2. アクション種別（ActionKind 全 32 種）

アクションは Java 版の継承階層ではなく `enum ActionKind` + `match` で表現しています。
Java 版の継承階層は基底クラスを含め約 40 種ですが、Rust 版は動作する種別を
32 variant に集約しています（基底クラス相当は variant 外）。

### 2-1. 基盤（3 種）

| 種別 | 機能 | 状態 |
|---|---|---|
| Animate | アニメーション（ポーズ）再生 | ✅ |
| Move | 基本移動 | ✅ |
| Stay | 静止 | ✅ |

### 2-2. 埋め込みアクション（10 種・資産で使用）

| 種別 | 機能 | 状態 |
|---|---|---|
| Fall | 落下 | ✅ |
| Jump | ジャンプ | ✅ |
| Dragged | ドラッグ（つかまれ） | ✅ |
| Regist | ウィンドウ反応の登録 | ✅ |
| Look | 向き変更 | ✅ |
| Offset | 相対位置オフセット | ✅ |
| Breed | 増殖 | ✅ |
| WalkWithIE | ウィンドウを保持して歩行 | ✅ |
| ThrowIE | ウィンドウを投げる | ✅ |
| FallWithIE | ウィンドウを保持して落下 | ✅ |

### 2-3. 構成アクション（2 種）

|---|---|---|
| Sequence | 子アクションを順に実行 | ✅ |
| Select | 条件に応じて子アクションを選択 | ✅ |

### 2-4. スタブ（17 種・資産未使用）

Java 版には存在しますが、同梱の `conf/actions.xml` からは参照されないため、
Rust 版では「即完了 + 警告ログ」のスタブとして動作します（挙動には影響しません）。

| 種別 | 機能 | 状態 |
|---|---|---|
| ScanMove | ウィンドウ探索しながら移動 | ⚠️ スタブ |
| ScanJump | ウィンドウ探索ジャンプ | ⚠️ スタブ |
| ScanInteract | ウィンドウ探索インタラクト | ⚠️ スタブ |
| BroadcastStay | 他個体へ静止を通知 | ⚠️ スタブ |
| BroadcastMove | 他個体へ移動を通知 | ⚠️ スタブ |
| BroadcastJump | 他個体へジャンプを通知 | ⚠️ スタブ |
| Broadcast | 他個体へ通知 | ⚠️ スタブ |
| ComplexMove | 複合移動 | ⚠️ スタブ |
| ComplexJump | 複合ジャンプ | ⚠️ スタブ |
| BreedMove | 増殖しながら移動 | ⚠️ スタブ |
| BreedJump | 増殖しながらジャンプ | ⚠️ スタブ |
| Interact | インタラクト（他個体・ウィンドウ反応） | ⚠️ スタブ |
| SelfDestruct | 自己消滅 | ⚠️ スタブ |
| Mute | 一時停止（ミュート） | ⚠️ スタブ |
