## 2. アクション種別（ActionKind 全 28 種）

アクションは Java 版の継承階層ではなく `enum ActionKind` + `match` で表現しています。
Java 版の継承階層は基底クラスを含め約 40 種ですが、Rust 版は動作する種別を
28 variant に集約しています（基底クラス相当と、override を持たない空サブクラス
4 種（Broadcast 系）は variant 外）。

| 種別 | 機能 | 状態 |
|---|---|---|
| Animate | アニメーション（ポーズ）再生 | ✅ |
| Move | 基本移動 | ✅ |
| Stay | 静止 | ✅ |

### 2-3b. アフォーダンス（放送 / 探索）

他個体へ「放送」して相手を探させ、到達したら互いの行動を差し替える仕組みです。
`Affordance` 属性を持つ行動が放送し、探索側が相手へ歩み寄って到達時に自分の行動と
相手の行動（`TargetBehavior`）を切り替えます。

| 種別 | 機能 | 状態 |
|---|---|---|
| Broadcast | 放送（アニメーション再生として動作） | ✅ |
| BroadcastStay | 放送（静止として動作） | ✅ |
| BroadcastMove | 放送（移動として動作） | ✅ |
| BroadcastJump | 放送（ジャンプとして動作） | ✅ |
| ScanMove | 放送中の相手を探して移動し、到達時に双方の行動を差し替え | ✅ |

> Java 版の `Broadcast*` は `Animate` / `Stay` / `Move` / `Jump` を継承し
> メソッドを 1 つも追加しない空サブクラスです（放送の実体は `Affordance` 属性）。

## 4. 設定・データ・スクリプト

| 機能 | 内容 | 状態 |
|---|---|---|
| XML パース | `conf/actions.xml` / `behaviors.xml` の強型パース（`<Constant>` / `<定数>` 含む） | ✅ |
| per-set 設定 | `img/<Set>/conf/` → `conf/<Set>/` → `conf/` の探索順で set ごとの `Actions.xml` / `Behavior.xml` を解決（同名アクションでも set ごとに別内容を持てる） | ✅ |
| スクリプト式評価 | `${}` / `#{}` のサブセット評価（四則・比較・三項・`Math.*`・`isOn()` 等。任意コード実行なし） | ✅ |
| 画像セット | `img/<SetName>/` を置くだけで認識。PNG ヘッダから寸法を動的取得 | ✅ |
| スケール | `conf/settings.toml` の set 単位 `scale`（Lanczos3 プリスケール） | ✅ |
| 設定の永続化 | `conf/settings.toml`（初回自動生成、トグル状態を保存） | ✅ |
| 多言語 UI | 埋め込み英語 + `conf/lang/en.toml` / `ja.toml`。`[general] language` で選択。Behavior 名（個別行動指定メニュー）も同じ辞書で解決 | ✅ |
| 効果音 | Pose の `Sound` / `Volume` 属性（鳴らしたい Pose にだけ書く）。`img/<Set>/sound/` → `sound/<Set>/` → `sound/` の探索順で WAV を Win32 `PlaySound` で再生し、再生終了ごとに鳴り直す（`Sounds` トグルで有効/無効） | ✅ |
| 画像セット作成ガイド | [`doc/imageset-guide.md`](imageset-guide.md) | ✅ |
